# Guía de Inicio Rápido

Bienvenido a **Extraer PDFs** — tu aplicación de gestión de documentos PDF todo en uno.

## ¿Qué puedo hacer?

- **Abrir y ver PDFs** en pestañas separadas
- **Anotar PDFs** — resaltar, subrayar, tachar, añadir notas y dibujar
- **Buscar texto** dentro de un PDF (Ctrl+F)
- **Extraer información** — palabras clave u OCR de múltiples PDFs
- **Combinar PDFs** — unir varios documentos en uno solo
- **Proteger con contraseña** — asegurar documentos sensibles
- **Censurar/Redactar** — ocultar información de forma permanente
- **Chatear con IA** — preguntar al documento o pedir análisis

## Primeros pasos

1. Haz clic en el menú **☰** (arriba a la izquierda)
2. Selecciona **Abrir PDF**
3. Elige un archivo PDF y abre
4. ¡Navega, anota, guarda!

## Guardado automático de anotaciones

Cualquier cambio que hagas (anotaciones, redacciones, etc.) se guarda en el propio archivo PDF cuando presionas **Ctrl+S**.

## Más información

Para conocer todas las funciones con detalle, consulta la sección "Información" en esta misma pestaña de Ayuda.
